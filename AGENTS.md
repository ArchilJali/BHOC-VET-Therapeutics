# BHOC Veterinary visual change rules

Read `WORK-STATE.md` before editing. It identifies the current artwork, latest user corrections, originals and exact scope.

1. Edit the named content block first. Read the current visual authority in WORK-STATE.md. Do not edit generated dist/index.html directly; rebuild it from content/ and src/. Preserve the supplied composition and site identity. Never regenerate the whole page or scene to change one animal, wording, colour or control.
2. Follow the user's explicit identity reference. Archil has identified assets/reference-dog-pencil.webp as Rem's canonical face for the species row. Preserve that exact face. Do not replace it with Eva, another photograph or a later generated interpretation. Original photographs are used only when a new task explicitly asks for a photo-based likeness correction.
3. For requested raster corrections, use a tightly bounded local ImageGen edit. Integrate only the permitted region into a new single flattened asset. No visible pasted patches, duplicate logo tiles or polygon holes in the scene.
4. Keep page copy, links, buttons and molecular diagrams native. Keep the approved artwork separate from responsive layout rules.
5. Check all pixels outside the intended change region. This verifies preservation only. Also inspect the face, fur continuity, seams and proportions visually.
6. For the visual checks Archil requested, compare the rendered desktop and narrow-width page with the retained composition and original photos. Inspect primary links, text wrapping and horizontal overflow. Use the supported Sites preview and Browser workflow. Report a blocked check honestly.
7. Publish only the concrete checked result within Archil's authorization. Do not call a file merely approved or unchanged as a substitute for checking what visitors see. Do not silently roll back to an earlier whole-scene version.
8. Preserve SEO identities, canonical URLs, meaningful ALT and existing links. No ornamental dash separators in prose. Inner pages are a separate next phase.
9. Never create or retain an outbound link to the HBO2 Therapeutics corporate website, and do not use that corporate website as an evidence source. If such a link is inherited in existing material, remove it. A company name may remain only where it is factual publication metadata or affiliation text and is not an outbound link.

Keep original dog photos and authoring images in the private Work source backend. Public GitHub publication uses only the necessary `dist/` files and project documentation, not private photo references.
