# Как менять сайт по блокам

Каждый блок хранится отдельно. Чтобы заменить предложение, подпись, ALT или ссылку, меняйте только нужное значение в его файле. Фотографии и рисунки при этом не меняются.

## Обычная правка

1. Откройте папку [content/blocks](content/blocks) в GitHub.
2. Выберите нужный файл, например [hero.json](content/blocks/hero.json).
3. Нажмите значок карандаша и измените текст справа от нужного названия поля.
4. Сохраните через **Commit changes**. Публикация выполняется через настроенный процесс GitHub Pages. Если проверка показывает ошибку, исправьте указанный файл. Последняя успешная публикация сохраняется.

В JSON нужны двойные кавычки и запятые между полями. Названия полей слева сохраняйте. Не вставляйте HTML в обычные текстовые поля. Для переноса строки в заголовке используйте следующий элемент массива.

```json
{
  "label": "Our science",
  "href": "#science"
}
```

`label` меняет подпись. `href` меняет адрес. Поле `dialog` открывает существующее информационное окно. Если вместо окна нужен переход на страницу, удалите поле `dialog` и укажите адрес страницы в `href`. Для карточки животного достаточно заменить `href` на адрес его будущей внутренней страницы.

## Как заменить изображение

Загрузите файл в `assets/`, затем обновите его `src`, `alt`, `width` и `height` в соответствующем блоке.

```json
{
  "src": "assets/research-photo.webp",
  "alt": "A veterinary researcher examining an animal blood sample",
  "width": 1200,
  "height": 800
}
```

ALT описывает то, что видно. Имя автора или список ключевых слов не нужно добавлять в описания животных. Для чисто декоративного фона используйте пустое значение `alt`.

## Как добавить новость или фотографию

Создайте `content/blocks/research-update.json`:

```json
{
  "id": "research-update",
  "eyebrow": "Research update",
  "heading": "Your update title",
  "paragraphs": ["Your first paragraph.", "Your next paragraph."],
  "link": {
    "label": "Read more",
    "href": "https://bhoctherapeutics.com/"
  }
}
```

При необходимости добавьте поле `image` по примеру выше и `caption` для подписи. Затем вставьте в нужное место массива `blocks` в [homepage.json](content/homepage.json):

```json
{
  "type": "story",
  "file": "blocks/research-update.json",
  "enabled": true
}
```

Новый блок получает собственный ID и свою высоту. Соседние блоки сохраняют содержание, рисунки и стили. Для изменения порядка перенесите запись в массиве. Перед отключением раздела обновите ссылки, которые на него ведут. Проверка не пропустит неработающие переходы.

## Как добавить карточку в Discover

В массив `slides` файла `science.json` можно добавить запись с `type: "story"`, `title`, `paragraphs` и необязательными `image` и `link`. Здесь могут быть фотографии, новости и другие интересные материалы. Молекулярные структуры остаются отдельным типом карточки.

## Если правка делается через Work

Достаточно сказать: «Измени текст только в блоке Science» или «Добавь новость после Species». Редактируется файл указанного блока, затем собирается и проверяется страница. Исходный рисунок не перерисовывается.

Ручная сборка для разработчика: `node scripts/build.mjs --out dist`, затем `node scripts/check-site.mjs dist`.
