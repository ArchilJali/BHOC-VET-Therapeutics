# Security Policy

## Reporting a security issue

Do not disclose suspected vulnerabilities, credentials, private keys, personal data, patient data, confidential partner information, or exploitation details in a public issue.

Report concerns privately to `info@bhoctherapeutics.com` with the affected URL, reproduction steps, impact, and supporting evidence.

## Supported version

Security fixes apply to the current `main` branch and live BHOC Veterinary deployment. Historical generated snapshots are not supported deployments.

## Public repository boundary

Every committed file must be safe for public access. Secrets, private contact intelligence, unpublished proprietary material, and sensitive personal or clinical data must not be committed.
