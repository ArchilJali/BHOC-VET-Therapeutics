# Veterinary homepage SEO implementation

Identity settings: `content/site.json`. Primary name BHOC Veterinary; alternatives BHOC Vet and BHOC Veterinary Therapeutics. Person metadata uses Archil Jaliashvili with given and family names and the supplied LinkedIn profile. The footer identifies him visibly. Organization and Person remain separate entities.

The homepage contains one semantic H1, a descriptive title and meta description, the canonical `https://bhocvet.com/`, index/follow directives, existing Open Graph and Twitter image metadata, and JSON-LD Organization, Person, WebSite, WebPage and ImageObject records. Section copy is compiled into HTML and does not depend on JavaScript or a content fetch. Alt text and intrinsic image dimensions are maintained next to each image record. The hero has priority loading, secondary portraits and diagrams are lazy loaded, and image URLs are included in the sitemap.

The search topic is veterinary oxygen carrier. Supporting biological and animal-health terminology is used in meaningful visible copy and structured metadata. No invisible keyword paragraphs or `meta keywords` tag are added. Shared vocabulary remains in the [corporate keyword authority](https://github.com/ArchilJali/BHOC-Therapeutics/blob/main/seo/BHOC-SEO-Keywords.md).
